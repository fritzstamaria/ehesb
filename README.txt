PROJECT eHES-B READY APP
This is a ready-to-host mobile web app/PWA prototype for Hinigaran Elementary School-B.

DEPLOY:
1. Upload all files to an HTTPS web host.
2. Open the hosted app on Android Chrome.
3. Choose Install app / Add to Home screen.
4. The app opens like a standalone mobile app.

The official Google Sites website is linked throughout the app.

For a production version with secure admin login, online database, photo uploads, push notifications and APK/Play Store packaging, connect this front end to a backend such as Firebase and deploy it under an official school-controlled web address.
